# 🥗 FitDiet — Healthy Living, Made Simple

**FitDiet** is a healthy food and nutrition website designed to help users explore nutritious recipes, understand their food choices, and plan balanced meals.

This project is a rebuilt version of my first-ever website, originally created during my first semester. I'm rebuilding it from scratch to strengthen my understanding of web development and transform it into a complete full-stack application.

## ✨ Project Goals

- Build a clean, modern, and responsive user interface.
- Make healthy recipes and nutrition information easy to explore.
- Create an interactive nutrition calculator.
- Enable users to organize and save meal plans.
- Develop a complete full-stack application with a backend and database.
- Learn and apply Git, GitHub, API integration, and deployment.

## 🚀 Planned Features

- 🏠 **Home Page** — Introduction to FitDiet and its features.
- 🥑 **Recipe Explorer** — Browse, search, and filter healthy recipes.
- 🧮 **Nutrition Calculator** — Estimate daily energy requirements using user inputs.
- 📅 **Meal Planner** — Organize meals for different days.
- 👤 **User Accounts** — Registration, login, and profile management.
- ❤️ **Saved Recipes** — Keep track of favorite recipes.
- 📱 **Responsive Design** — Support desktop, tablet, and mobile devices.

*Features will be implemented progressively as development continues.*
